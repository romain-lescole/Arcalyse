# 20. Raccourcis clavier et gestes de souris

| Raccourci / geste | Effet |
|---|---|
| **Tab** / **Maj+Tab** | Passe de commande en commande (boutons, menus, onglets, liens du détail, lignes de tableau) avec un contour visible. |
| **Entrée** / **Espace** | Active la commande qui a le focus ; dans une boîte de dialogue, Entrée = OK et Échap = annuler. |
| **Ctrl+K** | Champ 🔍 de la barre : vue, élément du modèle ou diagramme (↑ ↓ pour choisir, Entrée pour ouvrir). |
| **Alt+←** / **Alt+→** | Étape précédente / suivante de l'historique ◀ ▶ (vues, éléments du détail, diagrammes) ; aussi les boutons latéraux de la souris. |
| **Alt+4** | Ouvre ou ferme la console 📜 Scripts ; dans l'éditeur, **Ctrl+Entrée** exécute le script. |
| **Ctrl+S** / **Ctrl+Maj+S** | Enregistrer / enregistrer sous. |
| **Échap** | Ferme la fenêtre, le menu ou la sélection en cours. |
| **Ctrl +** / **Ctrl −** / **Ctrl+molette** | Zoom du graphe (Relation Map). |
| **Ctrl+W** | Ajuster la Relation Map à la fenêtre. |
| **Ctrl+F** | Recherche dans le diagramme ouvert (🔲 Diagrammes, tous formats) ; **Entrée** / **Maj+Entrée** : résultat suivant / précédent. |
| **F** / **G** / **Échap** | Diagramme ou vue d'un modèle SysML / UML ouvert dans 🔲 Diagrammes : centrer sur l'élément choisi / afficher ou masquer la grille / effacer la recherche. |
| **Flèches**, **Page ↑ / Page ↓**, **Entrée** / **Espace** | ▦ Matrice : passer d'une cellule à l'autre (10 lignes à la fois) ; détail de la cellule ([§ 25](25-matrice.md)). |
| **Ctrl+C** | Copier la sélection de cellules. |
| **Ctrl+Entrée** | Enregistrer un commentaire de revue. |
| **Ctrl/Cmd+clic**, **Maj+clic** | Sélection multiple (arborescence, cellules). |
| **Ctrl+V** | Colle une liste (texte ou Excel) sous l'élément sélectionné de l'arborescence de la Relation Map *(sans effet : la Relation Map est en lecture seule)*. |
| **Maj+molette** | Défilement horizontal (tableaux larges, scénarios). |
| **← →**, **Entrée**, **Échap** | Étapes d'une visite guidée (Entrée : suivante ; Échap : quitter). |
| **Double-clic** | Nouveau contexte (Relation Map) ; renommer un onglet ; détail d'une ligne du ▤ Tableau ; « uniquement celle-ci » sur un filtre d'allocation ; largeur auto d'une colonne (bord d'en-tête). |
| **Clic droit** | Menu contextuel (Relation Map, arborescence, explorateur de 🔲 Diagrammes : ouvrir, ⧉ fenêtre de comparaison, ℹ informations) ; commentaires de revue sur un élément (vues, diagrammes) ; commandes d'un bloc, d'un chapitre ou du plan dans un 📑 dossier. |
| **Ctrl+clic droit** | Dans une zone de saisie d'un 📑 dossier : menu d'Arcalyse au lieu de celui du navigateur. |
| **Glisser-déposer** | Ouvrir un fichier / dossier (sur la fenêtre ; une fois un modèle Capella ouvert, un `.aird` ou un fichier pure::variants le complète) ; élément ou diagramme sur un bloc texte d'un 📑 dossier (🔗 texte du modèle) ; réordonner colonnes et onglets ; déplacer / redimensionner un élément de tableau de bord ; cartes de 🏠 Projet (⚙ Disposer) ; palette 📎 — ou 🔲 / 🧭 / ⚡ vers une fenêtre séparée — vers check-lists et plans ; 📝 note de revue sur un diagramme ; trait depuis la poignée ● d'une note ; barre du ◧ volet de ⇄ Avant / après ; séparateurs de panneaux. |
