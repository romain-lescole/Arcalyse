# Annexe B — Formats d'export

| Format | Où |
|---|---|
| **Page HTML autonome** (application + modèle + votre travail) | 💾 (Ctrl+S), 📁 Fichier › 💾 Enregistrer sous… / 🌐 Télécharger la page HTML |
| **CSV** | ▤ Tableau, ▦ Matrice, ⚡ Chaînes, vues de 🏗 Architecture et de ✅ Vérifier (CSV enrichi : choix des colonnes), 🧩 SysML v2, 🧬 UML / SysML v1 et ses vues, 📑 ReqIF (chaque onglet), 🎚 Variantes, tableaux et matrices de Cameo (🔲 Diagrammes), Relation Map (arbre par niveaux, relations), 🔄 delta, ⚖ comparaison, 💬 revue, 🃏 Cartes |
| **Excel (.xlsx)** | tous les boutons ⬇ CSV quand **⚙ › Exports** est réglé sur Excel ; ▦ Matrice (⬇ Excel) ; **📁 Fichier › 📗 Classeur Excel des analyses** (une feuille par analyse) ; ⚖ Comparaison › 📋 Copier (tableau Excel) |
| **PDF** | ⚡ Chaînes (planches), 🔲 Diagrammes (planches ; vues SysML v2 : Imprimer / PDF), 📐 / ⚖ / rapports via 🖨 Imprimer |
| **ZIP PNG / SVG** | ⚡ Chaînes, 🔲 Diagrammes (planches) |
| **PNG / SVG / JPEG / copie d'image** | Relation Map, cartes de chaînes, 🔲 diagrammes Capella et vues SysML v2 (SVG, PNG, PNG ×2), Relation Map de Cameo (SVG), 🎬 Scénarios, 🖼 diagrammes calculés de 🚦 / 🎬 UML (PNG, SVG, 📋 Copier), ◎ Voisinage (PNG, SVG), ⇶ Liens entre couches (SVG, PNG), 📊 Métriques |
| **HTML (rapports)** | ⚡ Chaînes, 🔲 Diagrammes (planches), vues en blocs de 🏗 Architecture (vue ou toutes les vues), vues en blocs UML (🧱, ƒ), ƒ Fonctions (tableau, 📄 dossier fonctionnel, métriques), ⚖ comparaison, 📐 tableau de bord, 💬 rapport de revue, 📤 Faire relire des commentaires (page à renvoyer), 📑 dossiers et 📘 rapports (page HTML à commenter), ☑ check-lists et plans |
| **Word (.docx)** | 📑 dossiers et 📘 rapports (📝 Word), à faire commenter puis réimporter |
| **JSON** | vues (▤, 🗺), ▦ Matrice (définition), ⚙ interface et vues, 🩺 profil de contrôles, 📐 tableaux de bord, 🎨 thème, 💬 revue, 📤 réponses des relecteurs, 📑 retours, 🧩 modèles de rapport, ☑ check-lists, 🌳 arborescence |
| **Texte** | ≡ Texte des vues SysML v2 et des tableaux de Cameo ; 📜 Scripts (⬇ script `.js`, fichiers produits par `out.file`) |
| **Texte mis en forme / Markdown / tableau Excel** | ⚖ Comparaison › 📋 Copier |
